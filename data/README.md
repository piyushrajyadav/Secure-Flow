# SecureFlow data

| Path | What | Provenance |
|---|---|---|
| `corpora/v1.jsonl` | 30 attacks / 20 benign: the original manuscript's corpus | authors; v2 rules were tuned on it |
| `corpora/v2.jsonl` | 42 attacks / 37 benign (25 hard negatives) | authors; written before tuning, then its misses were used to tune, so **not held out** |
| `corpora/v3.jsonl` | 21 attacks / 24 benign | authors; **blind**: written after tuning, never tuned on. Deliberately includes weak spots |
| `corpora/MANIFEST.json` | SHA-256 and counts per file | generated by `python -m experiments.export_corpora` |
| `results/*.json` | every number in the paper | generated by `python -m experiments.run_all`; each file records the git commit that produced it |
| `results/llm_cache.jsonl` | every model request/response used by the model-in-the-loop results, pruned to the entries the experiments replay | re-derives `llm_*.json` with no network or key (`LLM_REPLAY=1`); exact model identifiers and parameters are in those result files |
| `external/injecagent/` | InjecAgent (MIT), pinned commit `f19c9f2` | **not redistributed**; fetched by `python -m experiments.external.fetch_injecagent` |

Record format (JSONL): `{"id", "corpus", "label": "attack"|"benign", "stratum", "text"}`. Non-ASCII and invisible
characters are stored as JSON `\uXXXX` escapes so the files are byte-stable.

**Handle with care:** the corpora contain adversarial prompt text. Treat them strictly as test data; never feed
them to an agent that has real tools or credentials.

**Limitations:** small, English-centric, authored by the detector's authors. Use them as regression tests, not as
a security guarantee. See `paper/main.tex` for the full discussion.
